# 🌿 comece aqui

Este é o caderno do **garden hermit**. Tudo o que está na pasta `notas` vira ficha no site.

## Plantar uma ficha nova

1. Clique em **Nova nota** (ou `Ctrl + N`). Ela já nasce na pasta `notas`.
2. Dê um título — o nome da nota é o título da ficha.
3. Aperte `Ctrl + P`, digite **modelo** e escolha **Inserir modelo → ficha**. Aparecem as propriedades:
   - **canteiro** — um destes: saúde · literatura · sociedade · natureza · relações · arte · universo · misticismo
   - **fonte** — revista, site ou autor (ex.: The New Yorker)
   - **link** — endereço do texto original
   - **maturidade** — semente · broto · arvore
4. Embaixo das propriedades, escreva o que quiser. É a sua nota.

## Escrever

- Parágrafos: deixe uma linha em branco entre eles.
- `**negrito**`, `*itálico*`, `==marca-texto==`
- `> citação` — começa a linha com `>`
- `- item` — listas
- **Ligar fichas:** digite `[[` e comece a escrever o nome de outra nota. No site, vira um link e aparece em "conversa com" / "citada em".
- **Imagens:** cole (`Ctrl + V`) direto na nota. Elas vão para a pasta `media`.

## Imagens do mural de um canteiro

- Arraste a imagem para a pasta do canteiro dentro de `mural` (ex.: `mural/arte`).
- O **nome do arquivo vira a legenda** — `Hilma af Klint, The Swan.jpg`. Nomes automáticos (`Pasted image…`, `IMG_…`) ficam sem legenda.
- Para escolher a ordem, comece o nome com `01 `, `02 `… (o número não aparece).

## Publicar

O plugin **Obsidian Git** envia suas mudanças para o GitHub sozinho (a cada alguns minutos). Para enviar na hora: `Ctrl + P` → **Obsidian Git: Commit and push**. Em 1–2 minutos o site atualiza.

## O que não vai para o site

- Esta nota, e qualquer coisa fora da pasta `notas`.
- Notas cujo nome começa com `_` (ex.: `_rascunho.md`) — servem de rascunho privado... **mas atenção:** o repositório é público, então quem procurar no GitHub consegue ler. Para coisas realmente privadas, use outro cofre do Obsidian.
